reflog-demo.txt
===============

What this is: a recording of my git reflog practice for Week 29 Day 5, Task 3.
Date: 23 November 2026
Where: PowerShell inside VS Code, in the Rahisisha repo, on a throwaway branch.

How it was made: I started PowerShell's recorder (Start-Transcript) and ran the
commands below. The recorder saved my commands but NOT Git's replies, so the
replies below were copied word for word from my terminal screen. The recorder's
header (computer and user details) was left out on purpose.

One PowerShell detail: HEAD@{1} must be written in quotes ("HEAD@{1}") in
PowerShell, because PowerShell treats @{ } as its own special symbol. My first
try without quotes failed with an error, and the second try with quotes worked.
Both are shown.

The story in four moves:
1. Make a throwaway branch (so main is never at risk).
2. Disaster: git reset --hard HEAD~3 throws away the last 3 commits.
3. Open the diary (git reflog) and find where I was before the mistake.
4. Rescue: git reset --hard "HEAD@{1}" brings the 3 commits back.
