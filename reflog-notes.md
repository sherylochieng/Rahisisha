I learned that the Git reflog is stored locally and records movements of HEAD, helping me recover previous commit positions. Reflog entries are usually retained for 90 days if reachable and 30 days if unreachable. However, reflog cannot recover files that were never committed, stashes that were never saved, or protect me from a remote force-push. I also learned that git fsck --lost-found can help locate dangling commits that are no longer referenced by a branch. This taught me that Git recovery tools are useful, but they have limitations. I should commit my work regularly, be careful with destructive commands, and understand how recovery tools work before relying on them.
